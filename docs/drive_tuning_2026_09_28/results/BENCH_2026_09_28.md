## 3. Key findings

1. **Firmware is 25.0.4, so kF = 0.000197 is in the right units.** With P = I = D = 0 and kF alone, a 1000 RPM command gave **about 1020 (L) and 1000 (R) RPM** off the ground, steady. On FW 25, parameter 16 is still kF in duty per RPM. The "12× too weak kV" hypothesis applies only to FW 26 (REV release notes: sm-26.1.0 "Adds expanded feedforward support"; REVLib 2026 "kV (formerly kF)").
2. **The old BURN failure (255) was the heartbeat.** It never really disabled the controllers. With the all-zero disabled heartbeat, BURN returns 0 on both.
3. **The feedback gains cause the low-speed hunting.** Off the ground at 200 RPM with the current P + I, speed swings about ±60 RPM, and at 0 RPM it wanders about ±50 RPM with overshoot into reverse. Feedforward alone at 1000 RPM was steady. Field tuning should start from feedforward and re-tune P and I (STRATEGY steps C–D).
4. **Speed-reading lag measured: about 140 ms** (reported STATUS_2 velocity vs velocity from position; one 1 V step, off the ground). REV's 112 ms filter estimate plus the 20 ms STATUS_2 period and bus timing is consistent with this.
5. **The right drivetrain has more friction:** at the same 5 % duty off the ground, L ≈ 183 RPM and R ≈ 165 RPM (about 10 %). Consistent with the earlier breakaway data (right about 2× left).

## 4. Consequences for the tuning strategy
- **kS per side** can't be set on the controller (no param 204 on FW 25). The options are:
  - (a) send it as **arbitrary feedforward** in the velocity setpoint frame (spec: bits 32–47, ×0.0009766, voltage units). This needs a small v2 addition plus host support;
  - (b) update the SPARKs to FW 26, which needs REV Hardware Client 2 and a re-review of every unit;
  - (c) rely on kF + P + I.
  Decide after the Session 1 identification shows how large kS is.
- **kF per side** works now (`KFL` / `KFR`). The step B fit gives it directly in duty per RPM: kF = kV_volts / bus voltage.
- **Idle mode:** decide Brake or Coast deliberately (stopping-distance test T9) and write it with `PW B idleMode 1` + BURN.
- **Current limit:** consider REV's 40–60 A. Record the choice and BURN it.
