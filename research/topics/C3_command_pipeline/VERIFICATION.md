**Most important corrections**
1. **Not supported, inverted (§2 line 61 and Disagreements line 308).** In issue #5524 the maintainer says that *open-loop* (open-loop controller + open-loop smoother) "could theoretically be better only if the odometry from the robot is delayed and/or inaccurate". The README says *closed loop* could be better in that case. Both statements need rewriting.
2. **A quote that is not in the file (§7 line 153).** The SPARK MAX "harder, 'but not impossible', to back-drive" quote does not appear in `rev_2026_sparkmax_operating_modes.md` or anywhere else in `sources/`.
3. **ros2_tracing overhead is not "per event" (Summary, §9 line 180, Key numbers).** 0.0033 ms is the mean end-to-end message-latency overhead of a publish→subscribe message with all instrumentation on (about 10 tracepoints), not the overhead of one event.
4. **IFA watchdog wording is narrower than the README says (Summary line 15, §4 line 92, Common mistakes lines 294 and 302).** The source text is about test equipment in the *Category 2* designated architecture. It rejects test equipment that is "engineered only in the form of software **and accesses OTE directly by means of a de-energizing signal generated by software**". The README drops the second half of that quote. p. 52 does not discuss e-stops at all.
5. **Page and section errors:** C3-S50 is p. 1:7 (not 1:8) and p. 1:13 (not 1:14); C3-S11 PLr table and the 27 safety functions are on p. 6 (not 7–9) and the 0.3 m/s value is on p. 7 (not p. 8); C3-S39 speed qualification is on p. 8 (not pp. 6–7); C3-S30 "never assume…" is under "Recommended Safe Work Procedures" (not "Performance Considerations"); in C3-S52 the quoted text is in the section "Rationale" (not "Motivation").
