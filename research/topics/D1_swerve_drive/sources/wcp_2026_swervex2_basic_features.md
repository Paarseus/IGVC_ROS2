# Basic Features

The Swerve X2 was built with a wide range of FRC use cases in mind, incorporating features that make it adaptable to a variety of applications. The basic features shared across all of the Swerve configurations are highlighted in the sections below.

## Hardware

The Swerve X2 was designed to streamline both assembly and maintenance by standardizing key parts across every configuration. Shared components, such as gears with integrated shafts and interchangeable ratio sets, make the module easier to build, service, and adapt to your team’s needs.

### Shafts

All gears in the Swerve X2 feature integrated shafts which help in reducing part count and improving reliability as shown below.

### Gear Ratios

The Swerve X2 supports a full range of gear ratios that are compatible with every module configuration. All ratios are available in both steel and aluminum versions, giving teams the option to balance durability and weight. Because the same gear ratios can be used across different configurations, modules can be mixed and matched without sacrificing performance.&#x20;

## Hole Patterns

### Bolt Circles

The motor plates on the Swerve X2 modules feature both a 2" bolt circle and a 1.375" bolt circle, ensuring compatibility with common FRC motors. This design provides a smoother user experience by eliminating the need for additional hardware.

{% hint style="warning" %}
The Standard Swerve X2 configuration is not included here as it is designed to be used with the 5/8" aluminum motor spacer. However, both the 2" and 1.375" bolt circles are built into the spacer itself, maintaining full motor compatibility.
{% endhint %}

### 1/2" Pitch Spacing

The Top Plate includes additional holes with 0.5" spacing, enabling users to mount additional hardware without custom machining. Meaning that these holes can be used to easily create stronger structures. Alternatively, these holes can also be used to mount other custom hardware onto the Swerve X2 modules while maintaining the [1/2" Pitch Spacing Standards](/welcome/frc-build-system/system-standards.md#id-1-2-pitch-spacing).

## Wheel Modules

The Swerve X2 Wheel Module is built for consistency, strength, and easy maintenance. All modules share the same wheel height, support multiple wheel options, and feature a simple removal process.

### Consistent Geometry

Every Swerve X2 configuration maintains the same wheel height, allowing modules to be mixed and matched seamlessly on the same robot without affecting drivetrain geometry.

{% hint style="info" %}
The  example below shows the Standard, Inverted, and Thin Configuration on a single drivetrain using the Top, Corner Mounting method to demonstrate the consistent wheel geometry.
{% endhint %}

{% hint style="warning" %}
&#x20;The dimension in the example is from the bottom face of the Bottom Support Plate to the ground. This dimension can be different depending on the use case.
{% endhint %}

### Fork Features

The Fork includes #10-32 tapped holes for custom wheel guard mounting and fully captures the 3.5" ID X-contact bearing, the 88t rotation gear, and the bearing retention plate to ensure strength and reliability.

<figure><img src="https://4022448544-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fv3U1blZmAL1arpmYDPqt%2Fuploads%2F5ys1s9lmlQvwNTJxFF3o%2FSwerve%20X2%20-%20Basic%20Features%20-%20Fork%20Features.svg?alt=media&amp;token=703653e5-6198-4aa5-b866-e93cb0e2ee1b" alt="" width="563"><figcaption></figcaption></figure>

The Forks also feature an integrated nut pocket that enables single-bolt wheel removal. This simplified system makes tread swaps quicker and easier, reducing downtime during competition.

<figure><img src="https://4022448544-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fv3U1blZmAL1arpmYDPqt%2Fuploads%2F69aloKsc18rxkYPExgKX%2FSwerve%20X2%20-%20Basic%20Features%20-%20Wheel%20Removal.svg?alt=media&amp;token=265b89bb-b4ae-42b0-9cf3-791b1bab8502" alt="" width="563"><figcaption></figcaption></figure>

### Wheel Options

The Swerve X2 supports 4" OD x 2" wide wheels, available in three options: an aluminum wheel with black neoprene tread, a molded high-grip wheel, and a Colson wheel to give teams the flexibility to match performance needs.
